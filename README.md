# 🛡️ EscudoMonitoreo

**EscudoMonitoreo** es una plataforma integral de ciberseguridad diseñada para el monitoreo de redes y simulación de amenazas en tiempo real. Este sistema utiliza una arquitectura robusta de microservicios.

## 🚀 Tecnologías y Stack
*   **Frontend:** Next.js 14+ (Tailwind CSS).
*   **Backend:** NestJS (TypeScript).
*   **Base de Datos:** PostgreSQL con Prisma ORM.
*   **Infraestructura:** Soporte para multi-tenant y Web3.

## 📦 Estructura del Monorepo
- `/backend`: API REST y lógica de monitoreo.
- `/dashboard`: Panel administrativo para visualización de datos.
- `/threat-simulator`: Módulo para pruebas de vulnerabilidades.

## ⚙️ Instalación y Uso
1. **Clonar el proyecto:**
   `git clone https://github.com/MiguelOllarves/EscudoMonitoreo.git`
2. **Instalar Dependencias:**
   Ejecuta `npm install` en cada subcarpeta.
3. **Variables de Entorno:**
   Configura tu archivo `.env` siguiendo el ejemplo de cada módulo.
